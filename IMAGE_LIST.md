# Image Sourcing List — Lymphedema/Lipedema Deck

**How this works**

1. Sara picks images from the links below.
2. Save each one using the **exact filename** in the `SAVE AS` column.
3. Drop them into the project folder.
4. I wire them into both the PowerPoint and the website in one pass.

Filenames matter — they map to slots already built into `content.json`.
Anything you skip just leaves that slot empty; nothing breaks.

**Format:** PNG or JPG. Aim for 1200px wide or larger. Bigger is fine, I downscale.
