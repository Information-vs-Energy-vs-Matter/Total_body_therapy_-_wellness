Site capabilities

This site is a static presentation platform. Here is what it can do now, what can be added, and what the trade-offs are.

Working now

Working today — no backend required

Scrolling presentation pages
Present live from a phone, tablet, or laptop; audience follows along on their own device.
Click-to-reveal quiz
Self-check questions that stay hidden until tapped. Runs entirely in the visitor's browser.
Large QR code
Scannable from the back of a room. Points audience straight to the presentation.
Outline page
Separate scannable agenda so viewers can jump to a section.
Multiple presentations
Each lives in its own subdirectory. The homepage lists them automatically.
Mobile-first layout
Built and tested at phone width first.
Print / save to PDF
Any page prints cleanly from the browser.
Instant updates
Edit content, rebuild, push — live in under a minute.
Can be added

Can be added — no backend, no cost

Stage comparison slider
Drag between two stages to see the progression.
Searchable glossary
Type a term, get the definition.
Progress tracking
Remembers which sections a visitor has read, on their device only.
Scored quiz mode
Timed or scored version with a results summary.
Downloadable handouts
PDF patient-education sheets linked from any section.
Embedded video
Technique demonstrations hosted on YouTube or Vimeo.
Speaker notes view
A presenter-only page with prompts, hidden from the public URL.
Language toggle
Spanish version of patient-facing content.
Needs a form service

Needs a form service — free tiers available

Anonymous question box
Audience types a question during the talk; it goes privately to the presenter's inbox. Nothing displays publicly.
Post-presentation feedback
Short survey; responses collected privately.
Contact / appointment request
Routes to the clinic inbox.
CE attendance sign-in
Collects attendee name and email for records.
Options: Web3Forms (up to 250 submissions/month free, no account needed), Basin (100/month free), or an embedded Google Form. All are host-independent and keep working if the site moves.
Not recommended

Deliberately not recommended

Public comment thread
Visitors would post personal health details — their surgeries, their limbs — publicly under the practice name, with no moderation queue and no way to retract. Use the private question box instead.
Live chat / advice widget
Creates an expectation of clinical advice outside a documented patient relationship.
Patient photo uploads
Identifiable health information on a public static host. Not appropriate without a HIPAA-compliant system.
Storing any patient data on this site
A static site has no secure storage. Anything genuinely confidential belongs in the clinic's EMR.

Hosting notes

Current host
GitHub Pages — free, unlimited bandwidth for this scale, requires the repository to be public.
Static only
GitHub Pages serves files. It cannot run server code, so anything storing data needs an outside service.
Netlify alternative
Netlify's free plan is 300 credits/month with production deploys at 15 credits each — roughly 20 deploys before the cap. Form submissions are now free and unlimited on credit plans. Free accounts cannot auto-recharge, so the cap is hard.
Recommendation
Stay on GitHub Pages for hosting. Add a third-party form endpoint if interactive input is wanted. This avoids the deploy-credit ceiling entirely.
